---
title: Personalized Recommendations
description: Build movie and series catalogs from your Simkl watch history.
---

Personalized Recommendations uses your Simkl watch history, ratings, and movie rewatches to generate movie and series catalogs in AIOStreams. The catalogs work with the existing Home and Discover views. A metadata addon that supports IMDb IDs supplies the full title and episode pages.

## Instance setup

Register one Simkl **AUTH V2** application for your AIOStreams instance. Choose **TV, devices & command line** for the device authorization flow. It requires a client ID and uses the Simkl PIN page, so there is no callback URL to register. [Simkl app registration and client types](https://api.simkl.org/api-reference/auth)

Set `SIMKL_CLIENT_ID` in the AIOStreams server's `.env` or deployment environment and restart the instance. If you use an existing **Server apps & services** registration, also set its `SIMKL_CLIENT_SECRET` on the server.

## Connect a viewer

1. Sign in to a saved AIOStreams configuration. Open **Miscellaneous → Recommendations** and enable **Personalized Recommendations**.
2. Choose the base configuration or a variant under **Simkl account scope**. Select **Connect Simkl**, open the approval link, and authorize access using the viewer’s Simkl account.
3. Return to AIOStreams and select **Check authorization**. The connection is saved immediately. Save the AIOStreams configuration to apply recommendation preferences.
4. Use the instance’s TMDB credential or configure your own under **Services → Metadata → TMDB**. Use **Recommendation Catalogs** to turn individual movie and series rows on or off for the selected scope. Save, then refresh **Addons → Catalogs** to reorder the active rows, grouped under **Recommendations (scope)**.

The first catalog load can take longer while AIOStreams fetches history and title metadata. The Addons catalog editor lists recommendation rows once they have results. Refresh the list after the initial generation finishes. The next catalog-list refresh can then show names such as **Because you watched Friends**, along with rows for individual favorite genres and themes. Afterward, the refresh interval controls how often catalog requests check for Simkl changes. The default is six hours. A request after that interval checks Simkl for changes. Changed history can update rows on that refresh. With unchanged history, a rebuild on the first eligible check after 24 hours advances the watched and loved seeds through up to three recent choices. Genre and theme titles follow the current taste profile. The previous rows remain available during a refresh or a temporary provider outage. A row can be empty if there are no suitable matches.

Under **Discovery Preferences**, use the two release-year handles to set a range. Leave the upper handle at **Now** to include releases through today. Select named movie and series genre chips to exclude them, or search TMDB to add keyword exclusions.

## Configuration variants

In **Simkl account scope**, select the variant and connect that viewer’s Simkl account. If a request selects multiple variants explicitly, the last explicitly selected variant supplies the account. If only automatic variants apply, the last automatic variant supplies the account. A variant without its own credentials has no personalized rows. For variant-specific discovery settings, set or merge the `personalizedRecommendations` configuration field in the variant script. Jellyfin personas should each be assigned a variant. Personas with the same effective variants share the linked Simkl account. If a persona has no effective variant or variant activation fails, its personalized rows are hidden.

## Built-in Simkl tracker for Jellyfin

Enable **Built-in Simkl tracker for Jellyfin** beside the Simkl connection for the desired scope and authorize write access. You can use the base scope for the primary Jellyfin user if they have no explicit variants. For each user with their own history, assign a dedicated variant in Jellyfin settings and connect that scope to the user's Simkl account. If multiple variants are active, the effective Simkl variant must be explicitly assigned and exclusive to that user. Shared histories and automatically selected tracker scopes are excluded.

The built-in tracker takes over tracking for that history. You can use a shared AIOMetadata configuration to supply title and episode metadata and turn off Simkl tracking there. Playback through Jellyfin sends start, pause, and stop events and manual watched changes. Jellyfin imports saved playback and watched history from Simkl using its normal watch-state refresh. Simkl's movie unwatch operation also removes the movie from its watchlist. To switch back to read-only access, turn off the tracker option and reauthorize.

## Privacy

AIOStreams sends the Simkl token to Simkl and uses watched title IDs to look up public metadata from TMDB. The server stores each connection’s encrypted access and refresh tokens separately from exported configuration. AIOStreams refreshes expiring tokens and requests read-only Simkl access unless you enable the built-in tracker. History and recommendation results are cached in server memory for the effective configuration. Anyone who has access to that configuration's personalized catalogs can see its recommendations, so treat install URLs and login credentials as private.

Turn on **Top Picks for You (Anime)** under Movies, Series, or both for the selected scope. These opt-in rows learn from the linked account’s Simkl anime history, including entries with a usable TMDB or IMDb mapping. The candidate pool uses Japanese animation from TMDB. Results use IMDb IDs for playback.
